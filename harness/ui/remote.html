Remote access

This app, on your phone, through a Cloudflare quick tunnel.

Off

Nothing is reachable from the internet

Turning this on starts cloudflared, which opens an outbound connection to Cloudflare and gives this app a public https://….trycloudflare.com address. No router change, no port forward, no certificate to install.

While it is on, anyone holding the pairing link can drive this app: read every stored chat, start runs, use the tools. Treat the link like a password.

Opening the tunnel…

cloudflared is asking Cloudflare for a hostname. This normally takes two to five seconds, and the pairing code appears here on its own.

What this really exposes

        

          A paired phone is an operator of this app: it can start runs, read every stored chat and use whatever tools
          the app has. The token is 256 random bits, held in this server's memory, minted when the tunnel starts and
          dropped when it stops, so restarting the app invalidates every link ever shared.
        

        

          The tunnel is a Cloudflare quick tunnel, not a VPN: it publishes this app and nothing else on the machine.
          Closing it closes the door completely. There are no user accounts, no expiry and no second factor - if you
          would not paste the link into a chat, do not leave the tunnel running.
