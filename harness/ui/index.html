                  Steps per message
                  100

                  Time per message
                  60 min

                  has. "No limit" leaves only the step limit and the stall watchdog.
                
              
                
              
              
                
                
                
                  Reviewer on every step
                  off
                
                
                
                
                  
                  
                
                
                
                A second model looks at each step that changes files or runs a changing
                  command, and speaks up only about concrete problems: a bug it can point at, a claim no test
                  backs, work drifting from the request. One short extra model call per step.
                
              
                
              
              
                
                
                
                  Load tools
                  when needed
                
                
                
                
                  
                  
                
                
                
                On, a quick question like a math problem is sent without the tool
                  definitions, which saves several thousand tokens a message and keeps small local models
                  from calling tools they don't need. The model loads the tools it needs itself, and they
                  stay loaded for the rest of the chat. Off sends every tool with every message.
                
              
                
              
                
                
                
                  Your browser

                Lets the agent read pages in your own browser with
                  your logins, and click and type there, inside embedded frames too (SolBrowser). Set up copies
                  the extension to a folder; load that folder once on your browser's extensions page with
                  Developer mode on. Reading asks nothing; clicking and typing ask first.
                
              
                
              
                What the agent may do without asking (access, sandbox, desktop control,
                commits, approval rules) is under Permissions. The context window is next to the message
                box, on the gauge.
                
            
                

            
            
                
              
                
                
                Accessthe composer's Access menu
                
                
                
                  
                  
                  
                  
                
                
                
                
              
                
              
                
                
                Auto approvaloff
                
                
                With Auto access, every action Workspace write would ask you about goes to a
                  reviewer model instead, which allows or refuses it with a reason the agent reads. Built-in deny rules
                  still deny, and after 3 refusals in a row (or 20 in one run) it goes back to asking you. A reviewer
                  that cannot be reached means it asks you.
                
              
                
              
              
                
                
                
                  Sandbox commands
                  off
                
                
                
                
                  
                  
                
                
                
                On, every command the agent runs is started in the
                  operating system's sandbox: it can read files but can only write inside the project folder
                  and its own temp folder. A command that would write anywhere else is refused by the system,
                  not by a rule the model could talk around. Background jobs are off while it is on.
                
              
                
              
              
                
                
                
                  Desktop control
                  off
                
                
                
                
                  
                  
                
                
                
                On, the agent gets desktop tools: a screenshot of the screen or
                  one window, the window list, and click, drag, scroll, type and key presses. Looking never asks;
                  every click, drag, scroll, keystroke or shortcut asks you first in Workspace write mode, and none
                  are allowed in Read only. Full access lets them run without asking. Needs a model that can see
                  images. Windows only.
                
              
                
              
                
                
                Commits in this folder
                
                
                
                  
                  
                  
                  
                
                
                
                The composer's Commits menu: how the agent commits finished work
                  in the folder this chat works in. It never pushes.
                
              
                
              
                
                
                Approval rules
                
                
                Your own rules, checked before the access level on every tool call, first match wins.
                  The pattern is matched against the command, the file path or the address, and * means
                  anything. "Always allow" on an approval card only lasts for that chat; a rule here lasts.
