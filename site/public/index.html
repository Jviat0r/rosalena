Run free AI models on your own PC

Rosalena Harness is a desktop app that runs AI models on your machine and on free cloud tiers, through one router that picks the model and switches when one is busy. Try the window in a browser first; nothing to install, no account, no key. I'm building it in public on one RTX 3090.

Try it

Chat with a free open model, running in your browser

Pick a model and press Load. It downloads once into your browser's cache and then runs on your own graphics card through WebGPU, so it works offline after that. Smaller models load faster; bigger ones answer better. This is a taste of local AI, not the full harness: the desktop app runs much larger models.

Needs Chrome or Edge on a computer with a graphics card (WebGPU). Phones mostly can't run it yet.
Load a model, then ask it something. Try "explain what VRAM is in two sentences".

Models come from the open-source WebLLM project and download from Hugging Face. Sizes shown are the graphics memory each one needs. Small models make mistakes, so check anything important.

What it does

One window for local and cloud models

Everything below works in the current build on my machine. What isn't built yet is on the download page.

⇄

One router

An OpenAI-compatible router on your PC. You ask for a job like "code", it picks the model, and if that model is busy or out of budget it falls back to the next one.

▣

Local first

Your own GPU is the first choice: free, private, no per-token bill. Free cloud tiers come next, then paid models only if you add a key.

✦

An agent that does tasks

It reads and writes files, runs tools, and hands parts of a job to subagents. Every run is logged so you can see what it did.

◎

Pictures, video, music

A ComfyUI plugin renders images, short clips and music on the same GPU, from saved workflow presets.

⌘

MCP server

Other tools can list your runs, read them, and start tasks through MCP. It can read your Claude Code and DSH sessions too, read-only.

◉

Voice input

Talk to it instead of typing. Speech is turned into text locally with Whisper, and it knows your project's own words so it gets function names right.

◧

Your own browser

With the SolBrowser extension the agent reads pages in your browser with your logins, and clicks and types there, even inside embedded frames. Public pages are read without opening a browser at all.

Measured

Same model, two harnesses

I ran Rosalena and OpenCode on the same local model, Qwen3-Coder 30B on my RTX 3090, through the same llama.cpp server. Eight small coding tasks, each graded by tests the agent never saw, one run per task with a 6 minute limit. It's a small test on one machine, not a leaderboard, and I'm adding more harnesses to it.
