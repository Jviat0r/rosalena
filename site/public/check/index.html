Can your PC run it?

This page reads the graphics card your browser is willing to describe, then sorts 10 local AI models into what runs comfortably, what runs with CPU offload, and what will not fit. Everything happens in this tab: nothing about your machine is sent anywhere.

This page guesses your card from what the browser exposes; the desktop app measures it with the driver, and the app is the thing that also runs the model. Treat every number below as a good second opinion, not a reading.

    No tokens per second, on purpose

    Speed depends on the model, the quant, the driver, the context length and whatever else is using the GPU, and a page that has not loaded the model cannot measure any of it. A made-up number would be worse than none, so this page does not show one. The desktop app runs the model, and can tell you what it actually did.

    How these numbers are made
    • Download size is the GGUF file size from the app's own model catalog, in decimal gigabytes as Hugging Face reports it.
    • KV cache is 2 × layers × context × kvDim × 2 bytes, at the context the app would serve the model with, not the length the model was trained for.
    • 0.5 GiB of runtime overhead covers the compute buffer and context initialisation.
    • A model fits when that total is at or under your card's VRAM. It runs tight when it is over VRAM but under your RAM, which means CPU offload.
    • The arithmetic is the desktop app's own, ported without changes, and a test pins the page to the app's byte results.
